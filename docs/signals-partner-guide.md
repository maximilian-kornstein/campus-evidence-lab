# CEL Signals Partner Guide

CEL Signals is a clearly automated public-interest wire that connects current campus developments to bounded, source-traceable evidence. It does not rank schools, infer misconduct, or convert documentation into prevalence claims.

## Subscribe

- National RSS: `/signals/feeds/all.xml`
- National JSON Feed: `/signals/feeds/all.json`
- Machine-readable artifact: `/data/signals.json`

Institution and topic feeds are generated as qualifying coverage grows.

## Embed a Context Note

```html
<script async src="https://campusevidencelab.org/signals/embed.js" data-signal="SIGNAL_ID"></script>
```

Embedded notes always link to their primary sources, claim boundary, and correction route. When a credible complaint is received, distribution pauses until a human reviewer resolves it.

## Corrections and counterevidence

Use the correction link on the Signal. CEL preserves the original history, immediately pauses credible disputes, and does not let automation adjudicate contested evidence.
