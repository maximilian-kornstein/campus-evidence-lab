# Application Evidence Checklist

Use this before submitting any application, resume, interview form, or counselor summary that mentions Campus Evidence Lab.

## 1. Recheck Current Numbers

Confirm these against the live project before you submit:

- record count
- school count
- source count
- brief count
- substantive institutional-response count
- school count with substantive responses

Pull from:

- `data/snapshot-manifest.json`
- `data/product-updates.json`
- the public site metrics

## 2. Recheck Outside-Review Claims

Only say a reviewer or organization engaged if one of these is true:

- they completed a documented review
- they gave concrete methodological feedback
- they explicitly allowed you to describe that review

Do not count:

- unanswered outreach
- informal encouragement
- “looks interesting”
- pending review

## 3. Recheck Public-Use Claims

Only say the archive was used by a journalist, researcher, student group, or organization if there is real documented use.

Good evidence:

- article citation
- email confirming use
- permission-based acknowledgment
- review memo
- meeting or written feedback tied to the archive

## 4. Prefer Infrastructure Claims Over Reputation Claims

Safer:

- built
- designed
- published
- documented
- audited
- verified
- structured
- exported

Avoid:

- proved
- measured campus safety
- ranked schools
- definitive
- comprehensive
- endorsed

## 5. Keep The Personal Story Brief

Use it to explain motivation, then move back to the work.

Good pattern:

- one sentence on motivation
- three to five sentences on what you built
- one sentence on what makes it rigorous

## 6. Best Evidence To Mention

The strongest evidence is:

- public site
- methodology
- updates log
- trust packet
- research workspace
- dataset snapshots
- source audits
- reviewer packet
- visible iteration over time

## 7. Best Short Closing Line

I wanted to build something that handled a sensitive topic with real evidence standards, not just attention.
