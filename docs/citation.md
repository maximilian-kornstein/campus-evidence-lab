# Citation Guidance

Preferred dataset citation:

Campus Evidence Lab. Dataset snapshot `snapshot_id`. Full snapshot hash `full_snapshot_hash`. Accessed `YYYY-MM-DD`. Record IDs: `evt_...`.

For a single record, cite:

- event ID
- event title or summary
- source URL
- record hash
- dataset snapshot ID
- full snapshot hash
- access date

For a brief, cite:

- brief title
- published date
- brief URL
- event dataset hash listed in the brief
- access date

Do not cite Campus Evidence Lab as a finding of legal liability. Cite it as an index of public-source records and use the linked primary source material for factual claims.
