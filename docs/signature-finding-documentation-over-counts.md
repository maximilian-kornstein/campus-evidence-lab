# Signature Finding: Documentation Over Counts

The most useful signal in Campus Evidence Lab is not a record count. It is whether a record can be traced through public source, classification rationale, review status, correction path, and release hash.

This finding does not rank schools, estimate frequency, score safety, or imply outside endorsement.

## Why This Matters

Counts are easy to misuse. Traceability is harder to fake. A record is more useful when a serious reader can inspect the source, understand the classification, see the confidence rationale, request a correction, and tie the record to a published snapshot.

## What To Inspect First

- Event Record Audit cards.
- Source pages and external source URLs.
- Public codebook definitions.
- Fixed review samples.
- Correction and duplicate-report paths.
- Release notes, snapshot manifest, and replication packet.
