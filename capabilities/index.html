Capability Ledger · Updated 2026-07-15

What is real, what is local, and what is still unproven.

This ledger separates software existence from live operation, and live operation from outside adoption or impact. Every capability has a bounded status, inspectable evidence, a verification date, and an explicit claim limit. There is no composite score.

Status definitions

Maturity categories, not quality rankings

production live
Publicly reachable and operated by an automated production workflow.
published static
Published and usable as static files or generated pages; not a hosted transactional service.
verification ready
Built and inspectable, but its strongest credibility claim still awaits outside use or review.
configured not adopted
Operational machinery exists, but CEL has not verified external adoption.
local only
Implemented for local verification only; no public network deployment is claimed.
