Status definitions

Maturity categories, not quality rankings

production live
Publicly reachable and operated by an automated production workflow.
published static
Published and usable as static files or generated pages; not a hosted transactional service.
feedback informed
Documented project-specific outside feedback has materially informed the implementation; this does not imply endorsement or peer review.
integration ready
A public, tested integration surface is available for independent use.
verifiable prototype
A complete public implementation and verifier exist; public-chain deployment is not required for local or browser verification.
