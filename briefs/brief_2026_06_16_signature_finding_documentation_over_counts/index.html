Signature Finding: Documentation Over Counts

The most useful signal in Campus Evidence Lab is not a record count. It is whether a record can be traced through public source, classification rationale, review status, correction path, and release hash.

Analysis Notes

  • Record counts are easy to misuse, while traceability forces a reviewer to inspect source support and classification choices.
  • The new Record Audit card, public codebook, fixed review samples, workflows, replication packet, and release notes make the archive more inspectable.
  • The strongest public claim is that a record can be traced through an evidence chain, not that the record count measures campus conditions.

Responsible Uses

  • Use this finding to prioritize source reading, auditability, corrections, and replication over raw counts.
  • Use counts only as navigation signals for where to inspect public documentation.
  • Pair any public use with the codebook, coverage limits, release notes, and source pages.

Method Note

This finding does not rank schools, estimate frequency, score safety, or imply outside endorsement.
