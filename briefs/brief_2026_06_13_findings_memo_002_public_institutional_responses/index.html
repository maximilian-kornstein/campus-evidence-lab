Findings Memo 002: What Public Institutional Responses Can and Cannot Show

Campus Evidence Lab published a findings memo explaining how the archive's 80 substantive public institutional responses across 67 schools should be read as a narrow documentation layer rather than evidence of which schools did or did not respond.

Analysis Notes

  • In the current 4,000-record snapshot spanning 947 schools, only 80 records contain a substantive public institutional response under the archive's current display rule, and 67 schools have at least one such response. That makes response visibility a useful but narrow documentation layer.
  • The response layer is strongest when it preserves a specific public statement, agreement, action, or procedural acknowledgment tied to a school or public body. In those cases, the archive documents not only that a matter entered the public record, but also part of how an institution responded in public.
  • Public institutional responses are much less common than event records overall because public reporting about an event and public institutional response to that event are different things with different source patterns and different discoverability.
  • The absence of a substantive public institutional response in the archive should not be treated as evidence that no response occurred. Missing response text marks a boundary of visible public documentation, not a finding of institutional silence or inaction.

Responsible Uses

  • Use the response layer to identify whether a public statement, agreement, or action is already visible before making institution-specific claims.
  • Do not convert response visibility into school rankings, campus safety claims, transparency scores, or moral judgments.
  • Pair any response-based interpretation with the methodology, source page, and the archive's documentation-not-prevalence limits.

Method Note

This memo uses the current public snapshot only: 4,000 event records across 947 schools. It excludes generic dataset disclaimer text from the response count and makes no claim that missing response text means no institutional response occurred.
