Submit / Correct

Public sources only.

The MVP accepts public-source suggestions, corrections, duplicate reports, and school metadata corrections. It does not accept private testimony, screenshots, direct messages, or sensitive personal information.

Free Intake System

Static MVP

The site can prepare structured source, correction, duplicate, and school metadata packets without a paid backend. Public deployment can route those packets through the repository issue templates or any free inbox later.

Read the contribution guide before opening a GitHub issue or pull request.

Required Fields

Source submissions

Public URL
Link to a campus newspaper article, university statement, public legal filing, government release, public safety notice, or reliable journalism.
School
Institution name, city, and state if known.
Community
The affected community supported by the public source.
Category
The best source-backed event category.
Reason
One sentence explaining why the source may meet the inclusion criteria.

Request a Correction

Source-backed only

Corrections should identify the record ID, the field that appears wrong, and the public source supporting the correction. Accepted corrections change the record hash, dataset hash, correction log, and event changelog.

Report a Duplicate

Source-backed only

Duplicate reports should identify both record IDs and explain, using public source material, why the records appear to describe the same underlying event or institutional action.

School Metadata Corrections

Profile fields only

School metadata corrections should identify the institution, the field to amend, and a public source supporting the requested change.

Do Not Submit

  • Private screenshots.
  • Direct messages.
  • Names of private individuals.
  • Unverified social media posts.
  • Sensitive personal information.
