Proof Path

Public accountability infrastructure, not a ranking.

This path gives a reader the shortest route from public institution briefings to machine-readable evidence artifacts, import-wave QA reports, and local verification commands. Current public artifacts include 150,000 accepted import-wave QA candidates and 10,000 public event records.

Open These First

A compact path through the public evidence system

  1. Accountability Room: browse institution briefings with source basis, limits, and response paths.
  2. Brown University: inspect one institution-level briefing with Accountability Signals.
  3. Import Waves: inspect accepted, duplicate, excluded, and quarantined counts from official-source imports.
  4. api/v1/index.json: open the public API index and discover institution endpoints, citation packets, source families, and snapshot metadata.
  5. Correction / right of reply: submit source-backed corrections, stronger locators, duplicate reports, or institution response evidence.
