Researcher Start

Try the archive with one narrow question.

Campus Evidence Lab is a public-source archive of U.S. postsecondary campus civil-rights records. Review is not endorsement; the point of this page is to make first use and critical feedback easier.

Use cases

Source-mix audit

Ask which public source types dominate a current snapshot, where source coverage is thin, and whether the source mix can support a specific research question.

Institutional-response scan

Search records for public institutional response text, then inspect source pages before treating response fields as documentation rather than complete behavior.

One-school public-record review

Open a school dossier, inspect its event timeline, then follow each event to source pages before citing or comparing records.

Reporter or literature scan

Use filters and downloads to find public records worth primary-source follow-up, not to infer prevalence, safety, severity, or institutional quality.

Five-minute trial

  1. Start with one question about public documentation, not prevalence.
  2. Open Events and filter by school, source type, community, category, or date.
  3. Open one event page and read the summary, verification label, confidence label, and limitations.
  4. Open the linked source page and, when available, the underlying public source URL.
  5. Use the Research Workspace to export a citation packet tied to the current snapshot hash.

What would make this easier to use?

  • Which research question did you try?
  • Where did the interface fail to explain source mix, scope, or limitations?
  • Which filters, fields, exports, or examples would make this more useful to researchers?
  • Which wording could still invite overclaiming?

Scope and limits

The current dataset covers postsecondary campus public records. It is not a PK-12 dataset, not a census, not a school ranking, not a safety score, and not a prevalence estimate. Coverage is shaped by public-source availability, under-reporting, source discovery, agency publication practices, campus transparency, and current reviewer capacity.
